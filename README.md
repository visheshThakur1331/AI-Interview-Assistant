# 🤖 AI Interview Assistant & Mock Interview Platform

## 📌 Overview

AI Interview Assistant is a web-based technical interview preparation platform built using Java and Spring Boot.

The platform helps students and interview candidates practice technical interviews through structured interview modules and track their performance.

## ✨ Features

- 🔐 User Registration and Authentication
- 💻 Technical Interview Modules
- ☕ Java Interview Questions
- 🗄️ DBMS Interview Questions
- 🌐 JavaScript Interview Questions
- 🍃 Spring Boot Interview Questions
- 🧠 Object-Oriented Programming Questions
- 📊 Dashboard and Performance Analytics
- 🏆 Leaderboard
- 📚 Interview History
- 📜 Certificate Generation

## 🛠️ Technologies Used

## 🎯 Interview Modules

The platform provides interview preparation in multiple technical areas:

- Java
- DBMS
- JavaScript
- Spring Boot
- Object-Oriented Programming

## 📊 User Features

Users can:

1. Register and log in
2. Select technical interview modules
3. Attempt interview questions
4. Track interview history
5. View performance analytics
6. Compare performance through the leaderboard
7. Generate an interview certificate
